## Hey, I'm  Aleksandr Minkin 👋

I build developer tools, product prototypes and web systems with a strong focus on clarity, structure and maintainability.

Most of my work sits somewhere between frontend, backend and platform thinking.  
I like turning vague ideas into usable products, and complex flows into systems that are easier to reason about.

You'll find TypeScript everywhere, along with React, Next.js, NestJS, Vue, parsing tools, SDK generators, dashboards and personal experiments.  
Some projects are product-oriented, some are infrastructure-minded, and some are just me exploring how to make software feel cleaner and more deliberate.

I care about good architecture, readable code and interfaces that are simple without being dull.

Feel free to fork something or open a PR if you spot an issue or have an idea.
